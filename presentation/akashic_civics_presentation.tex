\slide{The Civic Problem: Democracy Without Data}

Local criminal justice decisions shape lives -- but they are invisible.  District attorneys, sheriffs, and judges exercise enormous discretion over arrests, charges, bonds, sentences, and parole.  Race, income, and neighborhood predict outcomes more reliably than the law should.  Yet without measurement, communities cannot name it, cannot challenge it, cannot change it.  \\
\textbf{Why justice requires measurement:} Transparency is the minimum condition for accountability in a democracy.

\slide{What We're Building: Tools for Community Power}

Akashic Civics is open-source infrastructure that helps communities turn fragmented local data into actionable insight.  We combine statistical rigor with civic accessibility: \texttt{TypeScript $\to$ Python $\to$ R}, modular extensions, and dashboards designed for journalists, researchers, and activists.  \\
\textbf{The vision:} Data belongs to the community, not to the prosecutor.

\slide{Design Principles: Multi-language, Statistical, Composable}

Two principles drive everything we build:\\
(1) \textbf{Multi-language by design} -- Meet users where they are (policy researchers use R, data scientists use Python, civic tech uses TypeScript).\\
(2) \textbf{Statistical rigor first} -- No headline numbers without confidence intervals and causal interpretation.\\
(3) \textbf{Composable, not monolithic} -- Use the dashboard, the CLI, or just the R package.\\
\textbf{Why this matters:} Tools must fit into existing practices, not reinvent them.

\slide{E16: Data Integration -- The Foundation of Everything}

\textbf{Data hides in silos.}  FBI UCR, BJS, and local court systems store 90\% of what we need -- but in incompatible formats.  Pluggable \texttt{DataSource} interfaces and a \texttt{DataPipeline} that normalizes to a common schema make analysis possible.  \\
\textbf{For democracy:} If data stays trapped in silos, communities stay powerless.  9 tests ensure reliability across data sources.

\slide{E17: Advanced Analytics -- Causal, Not Just Correlational}

\textbf{Rates lie.}  A 1.4$\times$ conviction rate disparity might mean bias -- or just different crimes.  \texttt{DoublyRobustEstimator} protects against model misspecification; \texttt{BayesianHierarchicalModel} stabilizes estimates in small jurisdictions.  \\
\textbf{For justice:} Causal methods answer ``Did this policy cause disparity?'' not ``Are they correlated?''  This is how we move from observation to evidence-based reform.

\slide{E18: Interactive CLI Wizard -- Tools for Everyone}

\textbf{No PhD required.}  Non-programmers can load data, choose Jurisdiction, select analysis type, and get results in five steps.  The wizard abstracts technical complexity while preserving methodological choices.  \\
\textbf{For democracy:} When tools are usable, power diffuses.  A civic organizer, not a statistician, can make the case to their DA.

\slide{E19: Jupyter Notebook Interface -- The Analyst's Playground}

\textbf{Python users want magic,} not CLI flags.  IPython magics (\texttt{\%akashic}), rendered report templates, and direct NumPy/SciPy integration let analysts iterate interactively.  \\
\textbf{For justice:} Analysts can prototype, explore, and build public-facing narratives.  When research is reproducible in a notebook, findings become shareable across coalitions.

\slide{E20: Publishing Pipeline -- Open Source Cannot Collapse}

Open-source projects die.  An 11-step release pipeline (\texttt{npm publish}, \texttt{pip install}, \texttt{R CMD INSTALL}, \texttt{docker push}, automated testing, changelogs) keeps code current and trustworthy.  \\
\textbf{For democracy:} Sustainability ensures tools survive grant cycles and volunteer turnover.  Code must be a public good, not a one-person effort.

\slide{E21: Extension System -- Communities Add Their Own Power}

\textbf{Needs differ.}  A Native American tribal court needs different data sources than urban DA's office.  \texttt{ExtensionRegistry} lets communities ship custom plugins for DataSources, Analyses, and Exports.  \\
\textbf{For democracy:} Tools adapt to local contexts instead of requiring local coding skills.  Community ownership starts with modular architecture.

\slide{E22: R Package -- Speaking Policy's Language}

\textbf{Policy researchers think in models, not APIs.}  The \texttt{akashic.civics} R package provides OLS, logistic regression, doubly-robust estimation, and disconfirmation batteries familiar to criminologists and political scientists.  \texttt{R CMD check} compliant, with vignettes.  \\
\textbf{For justice:} When academic researchers can run the same analysis, findings carry weight in scholarly and policy debates.

\slide{E23: Streaming Analysis -- Justice in (Near) Real Time}

\textbf{Disparity moves fast.}  Policy changes, court closures, or surges in specific crime types can shift ratios dramatically.  \texttt{StreamProcessor} reads JSONL in chunks, tracks group-level statistics, and fires alerts when disparity crosses thresholds.  \\
\textbf{For democracy:} Real-time monitoring turns reactive analysis into proactive intervention.  When the ratio jumps, advocates know to act.

\slide{E24: Web Dashboard UI -- Storytelling for Citizens}

\textbf{Most users won't run code.}  An Express REST API (\texttt{/api/health}, \texttt{/api/viz-specs}, \texttt{/api/analyze}) powers a static single-page app showing disparity ratios, conviction rates, and sentence lengths.  \\
\textbf{For justice:} When disparities are visible on a dashboard in a community meeting, officials must confront them.

\slide{E25: Python Statistical Depth -- Scientific Rigor, Not Guesswork}

\textbf{Numbers must be right.}  Real NumPy/SciPy implementations of descriptive statistics, Z-tests, OLS, logistic regression, doubly-robust estimation, and disconfirmation batteries replace placeholder functions.  Error handling with informative messages.  \\
\textbf{For democracy:} Communities can trust that their analysis withstands peer review, Freedom of Information Act challenges, and expert scrutiny.

\slide{A Concrete Democracy in Action}

\textbf{Scenario.}  Mid-sized county, 12,000 cases/year.  A community group loads 3 years of data into Akashic Civics.  Doubly-robust analysis: Black defendants convicted at 1.4$\times$ rate of White defendants ($p<0.01$).  Streaming alert: ratio jumped from 1.2$\times$ to 1.6$\times$ after new DA took office.  Group presents findings at public safety committee hearing.  DA adopts new charging guidelines.  Next quarter: disparity drops to 1.1$\times$.\\[0.5em]
\textbf{Key:} Measurement enabled accountability; accountability drove policy change; policy change reduced disparity.

\slide{Toward a More Just Democracy}

\begin{itemize}
    \item \textbf{Transparency:} Disparity metrics no longer locked in prosecutors' spreadsheets
    \item \textbf{Participation:} Community groups analyze the same data as officials
    \item \textbf{Accountability:} Elected leaders evaluated on measurable outcomes
    \item \textbf{Reform Evaluation:} Did the policy actually reduce disparity?  We can tell.
\end{itemize}
